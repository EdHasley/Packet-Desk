Packet Desk • Kantronics TNC Command Help

At cmd: type HELP for every command on the connected firmware.
Type HELP followed by a command name for its built-in description.
Type HELP C* for commands beginning with C.
Type VERSION to see your firmware revision.

These offline indexes point to the Terminal Command Reference in each
manual. Commands inside a mailbox or node use the help at that prompt.
