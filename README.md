# Packet Desk 0.3.0

Packet Desk is a desktop serial terminal for Kantronics TNCs operating in TERMINAL mode. It runs on Debian-based Linux desktops and Raspberry Pi OS with a graphical session.

Download `packet-desk_0.3.0_all.deb`, then install it from your download directory:

```sh
sudo apt install ./packet-desk_0.3.0_all.deb
```

Launch Packet Desk from the application menu or run `packet-desk`.

See [START-HERE.txt](START-HERE.txt) for build and test instructions. The complete ZIP bundles the installer, source, tests, and documentation.
